# Alltag

Mobile-first PWA für das iPhone. Enthält Ausgaben/Einnahmen, Monatsbudget, Sparziele, Auto- und Tankkosten, Mood-Tracker sowie eine schnelle Merkliste.

## Besonderheiten
- komplett ohne Backend
- alle persönlichen Daten bleiben lokal auf dem Gerät
- offline nach dem ersten Laden nutzbar
- JSON-Backup/Restore in den Einstellungen
- als iPhone-Web-App über Safari installierbar

## Lokal starten
Ein beliebiger statischer Webserver reicht, z. B.:

```bash
python -m http.server 8080
```

Dann `http://localhost:8080` öffnen.
